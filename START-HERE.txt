MIRRORFORGE V1 — GETTING STARTED
================================

1) For Windows users, the easiest path is to wait for the GitHub Actions release build and download the Windows installer or portable EXE from the repository's Releases page.
2) To run from source, install Node.js 22, extract the source, open a terminal in the folder, run `npm install`, then `npm start`.
3) On first launch, create the administrator account locally on the PC. Use a strong password (12+ characters).
4) In the dashboard create a screen, add widgets, then create a display device. Open its display URL on a phone, tablet, Android TV or mirror browser.
5) For access outside home Wi-Fi, use a secured HTTPS tunnel/reverse proxy. Do not expose the raw HTTP port directly to the public internet.
6) Mobile clients are built by GitHub Actions. The Android APK is debug-signed for private sideloading; the iOS IPA is unsigned and requires re-signing/provisioning or a compatible jailbreak workflow.
7) The matching licence issuer private key is delivered as a separate file. If using licensing, copy it to `secrets/license-private.pem` on your issuer host. Never upload that file, issuer tokens, Apple signing credentials, or Android keystores to GitHub.

See README.md, docs/DEPLOYMENT.md, docs/LICENSING.md and docs/RELEASES.md for details.
